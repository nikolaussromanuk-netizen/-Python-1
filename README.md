## Задания

### Задание 1: Нарисовать в консоли флаг Финляндии
Функция: `draw_flag(width, length)`

Рисует флаг Финляндии заданного размера.
- Пример вызова: `draw_flag(18, 6)`
- Минимальные значения: `width=18`, `length=3`

### Задание 2: Нарисовать в консоли узор из кругов
Функция: `draw_pattern(n, r)`

Рисует `n` кругов радиуса `r`, стоящих вплотную друг к другу.
- Пример вызова: `draw_pattern(4, 4)`
- Радиус приводится к чётному (при нечётном ломается симметрия)

### Задание 3: Сделать анимацию на 3-4 кадра в терминале
Функция `draw_animation()`

Делает анимацию на 4 кадра, которая рисует переключающийся светофор

## Как запустить
Раскомментировать нужный вызов в блоке `if __name__ == "__main__"` и выполнить:
```bash
python lab.py
```
